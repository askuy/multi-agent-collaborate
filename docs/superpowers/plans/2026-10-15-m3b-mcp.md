# M3b: MCP Server — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let MCP agents (Claude Code, Codex, Cursor) use Trellis directly through `tl mcp`, a stdio MCP server exposing sessions, files, landing, conflicts, intents, notifications, tasks, the log, and leases as tools.

**Architecture:** A new `trellis-mcp` crate implements the MCP stdio transport by hand: JSON-RPC 2.0, one message per line, with `initialize`, `ping`, `tools/list`, and `tools/call` (the subset a tools-only server needs; no SDK dependency). Each `tl mcp` process is one agent (`--as`): it keeps the agent's current session and forwards every tool call to the shared Trellis server through `trellis-client`, so many agents stay safe behind the one server's locks. Tool failures are tool results with `isError: true` (MCP's convention), not protocol errors. Every tool result carries the session's notifications not yet shown (spec §5.2: pending notifications ride along with each response), so agents learn about changes to what they read without push support. `initialize` returns `instructions` that teach the collaboration workflow.

**Tech Stack:** `serde_json`; `trellis-client`.

**Spec:** §5.2 (MCP tools), §4.3 (notifications), §4.5 (log).

```rust
use std::io::{self, BufRead, Write};

use serde_json::{Value, json};
use trellis_client::Client;

use crate::tools::{self, Agent};

/// MCP protocol versions this server speaks, newest first.
pub const SUPPORTED_VERSIONS: [&str; 3] = ["2025-06-18", "2025-03-26", "2024-11-05"];

/// One agent's MCP server.
pub struct Server {
    agent: Agent,
}

fn response(id: Value, result: Result<Value, (i64, String)>) -> Value {
    match result {
        Ok(result) => json!({ "jsonrpc": "2.0", "id": id, "result": result }),
        Err((code, message)) => json!({ "jsonrpc": "2.0", "id": id, "error": { "code": code, "message": message } }),
    }
}

impl Server {
    pub fn new(client: Client, principal: impl Into<String>) -> Self {
        Self { agent: Agent::new(client, principal.into()) }
    }

    /// Handles one JSON-RPC message: the response for a request, `None` for a notification.
    pub fn handle(&mut self, message: &Value) -> Option<Value> {
        let id = message.get("id").cloned()?;
        let method = message.get("method").and_then(Value::as_str).unwrap_or_default();
        let params = message.get("params").cloned().unwrap_or(Value::Null);
        let result = match method {
            "initialize" => Ok(initialize(&params)),
            "ping" => Ok(json!({})),
            "tools/list" => Ok(json!({ "tools": tools::definitions() })),
            "tools/call" => {
                let name = params.get("name").and_then(Value::as_str).unwrap_or_default();
                let arguments = params.get("arguments").cloned().unwrap_or_else(|| json!({}));
                Ok(self.agent.call(name, &arguments))
            }
            _ => Err((-32601, format!("method not found: {method}"))),
        };
        Some(response(id, result))
    }
}

fn initialize(params: &Value) -> Value {
    let requested = params.get("protocolVersion").and_then(Value::as_str).unwrap_or_default();
    let version = if SUPPORTED_VERSIONS.contains(&requested) { requested } else { SUPPORTED_VERSIONS[0] };
    json!({
        "protocolVersion": version,
        "capabilities": { "tools": { "listChanged": false } },
        "serverInfo": { "name": "trellis", "version": env!("CARGO_PKG_VERSION") },
        "instructions": tools::INSTRUCTIONS,
    })
}

/// Serves MCP over stdin/stdout until stdin closes.
pub fn serve_stdio(mut server: Server) -> io::Result<()> {
    let stdin = io::stdin();
    let mut stdout = io::stdout().lock();
    for line in stdin.lock().lines() {
        let line = line?;
        if line.trim().is_empty() {
            continue;
        }
        let reply = match serde_json::from_str::<Value>(&line) {
            Ok(message) => server.handle(&message),
            Err(e) => Some(response(Value::Null, Err((-32700, format!("parse error: {e}"))))),
        };
        if let Some(reply) = reply {
            writeln!(stdout, "{reply}")?;
            stdout.flush()?;
        }
    }
    Ok(())
}

/// One agent: its identity, its current session, and the notifications already shown.
pub struct Agent {
    client: Client,
    principal: String,
    session: Option<String>,
    shown_seq: u64,
    next_key: u64,
}

type ToolResult = Result<Value, String>;

fn arg(args: &Value, key: &str) -> Result<String, String> {
    args.get(key).and_then(Value::as_str).map(str::to_owned).ok_or_else(|| format!("missing string argument `{key}`"))
}

fn opt(args: &Value, key: &str) -> Option<String> {
    args.get(key).and_then(Value::as_str).map(str::to_owned)
}

fn list(args: &Value, key: &str) -> Vec<String> {
    args.get(key)
        .and_then(Value::as_array)
        .map(|items| items.iter().filter_map(Value::as_str).map(str::to_owned).collect())
        .unwrap_or_default()
}

fn scopes(args: &Value, key: &str) -> Result<Vec<Scope>, String> {
    list(args, key).iter().map(|s| Scope::parse(s).map_err(|e| e.to_string())).collect()
}

fn failed(e: ClientError) -> String {
    e.to_string()
}

fn to_json<T: serde::Serialize>(value: &T) -> ToolResult {
    serde_json::to_value(value).map_err(|e| e.to_string())
}

impl Agent {
    pub fn new(client: Client, principal: String) -> Self {
        Self { client, principal, session: None, shown_seq: 0, next_key: 0 }
    }

    /// Runs a tool and wraps the outcome as an MCP tool result.
    pub fn call(&mut self, name: &str, args: &Value) -> Value {
        let (mut text, is_error) = match self.dispatch(name, args) {
            Ok(Value::String(text)) => (text, false),
            Ok(value) => (serde_json::to_string_pretty(&value).unwrap_or_default(), false),
            Err(message) => (message, true),
        };
        if let Some(notes) = self.pending_notes() {
            text.push_str(&notes);
        }
        json!({ "content": [{ "type": "text", "text": text }], "isError": is_error })
    }

    fn session(&self) -> Result<String, String> {
        self.session.clone().ok_or_else(|| "no open session: call session_open first".to_owned())
    }

    /// Notifications not yet shown to this agent, as a trailer for the next tool result.
    fn pending_notes(&mut self) -> Option<String> {
        let session = self.session.clone()?;
        let notes = self.client.notifications(&session).ok()?;
        let fresh: Vec<_> = notes.into_iter().filter(|n| n.seq > self.shown_seq).collect();
        self.shown_seq = fresh.last()?.seq;
        let lines: Vec<String> = fresh
            .iter()
            .map(|n| {
                let paths: Vec<&str> = n.paths.iter().map(|p| p.as_str()).collect();
                format!("- {} landed \"{}\" (seq {}), touching {}", n.author, n.message, n.seq, paths.join(", "))
            })
            .collect();
        Some(format!(
            "\n\n[trellis] {} change(s) landed on files you read or watch. Decide whether your plan still holds; if not, rebase and re-read them:\n{}",
            fresh.len(),
            lines.join("\n")
        ))
    }

    fn dispatch(&mut self, name: &str, args: &Value) -> ToolResult {
        let c = &self.client;
        match name {
            "session_open" => {
                if let Some(session) = &self.session {
                    return Ok(json!({ "session": session, "note": "a session is already open" }));
                }
                let record = c.open_session(&self.principal, opt(args, "task").as_deref()).map_err(failed)?;
                self.session = Some(record.id.clone());
                self.shown_seq = 0;
                Ok(json!({ "session": record.id, "base": record.base, "task": record.task }))
            }
            "session_close" => {
                let session = self.session()?;
                c.close_session(&session).map_err(failed)?;
                self.session = None;
                Ok(json!({ "closed": session }))
            }
            "read" => {
                let path = arg(args, "path")?;
                match c.read(&self.session()?, &path).map_err(failed)? {
                    Some(bytes) => String::from_utf8(bytes)
                        .map(Value::String)
                        .map_err(|_| format!("{path} is a binary file")),
                    None => Err(format!("{path} does not exist")),
                }
            }
            "write" => {
                let path = arg(args, "path")?;
                c.write(&self.session()?, &path, arg(args, "content")?.as_bytes()).map_err(failed)?;
                Ok(json!({ "written": path }))
            }
            "delete" => {
                let path = arg(args, "path")?;
                c.delete(&self.session()?, &path).map_err(failed)?;
                Ok(json!({ "deleted": path }))
            }
            "list" => {
                let scope: Vec<String> = opt(args, "scope").into_iter().collect();
                let files = c.files(&self.session()?, &scope).map_err(failed)?;
                let lines: Vec<String> = files
                    .iter()
                    .map(|f| if f.changed { format!("{} (changed)", f.path) } else { f.path.to_string() })
                    .collect();
                Ok(Value::String(if lines.is_empty() { "(no files)".into() } else { lines.join("\n") }))
            }
            "land" => {
                let session = self.session()?;
                let key = format!("mcp-{session}-{}", self.next_key);
                self.next_key += 1;
                let receipt = c.land(&session, &arg(args, "message")?, &key).map_err(failed)?;
                let next = match &receipt.outcome {
                    Outcome::Landed { .. } | Outcome::Unchanged { .. } => {
                        self.session = None;
                        "Session finished. Call session_open for more work."
                    }
                    Outcome::Conflicted { .. } => "Call conflict_show, then conflict_resolve, then land again.",
                    Outcome::Rejected { .. } => "Call rebase, re-check the affected files, then land again.",
                };
                Ok(json!({ "receipt": receipt, "next": next }))
            }
            "rebase" => {
                let session = self.session()?;
                let outcome = c.rebase(&session).map_err(failed)?;
                if matches!(outcome, RebaseOutcome::AlreadyLanded { .. }) {
                    self.session = None;
                }
                to_json(&outcome)
            }
            "intent" => {
                let ttl_seconds = args.get("ttl_seconds").and_then(Value::as_i64).unwrap_or(600);
                let intent = Intent {
                    description: arg(args, "description")?,
                    reads: scopes(args, "reads")?,
                    writes: scopes(args, "writes")?,
                    exclusive: args.get("exclusive").and_then(Value::as_bool).unwrap_or(false),
                    ttl_ms: ttl_seconds * 1000,
                };
                to_json(&c.declare_intent(&self.session()?, &intent).map_err(failed)?)
            }
            "notifications" => {
                let session = self.session()?;
                let notes = c.notifications(&session).map_err(failed)?;
                if let Some(last) = notes.last() {
                    self.shown_seq = self.shown_seq.max(last.seq);
                    if args.get("ack").and_then(Value::as_bool).unwrap_or(false) {
                        c.ack_notifications(&session, last.seq).map_err(failed)?;
                    }
                }
                to_json(&notes)
            }
            "conflicts" => to_json(&c.conflicts(true).map_err(failed)?),
            "conflict_show" => to_json(&c.conflict(&arg(args, "id")?).map_err(failed)?),
            "conflict_resolve" => {
                let mut resolutions = BTreeMap::new();
                for (path, text) in args.get("resolutions").and_then(Value::as_object).ok_or("missing object argument `resolutions`")? {
                    resolutions.insert(path.clone(), text.as_str().map(str::to_owned));
                }
                to_json(&c.resolve_conflict(&arg(args, "id")?, &resolutions).map_err(failed)?)
            }
            "task_list" => to_json(&c.tasks().map_err(failed)?),
            "task_create" => to_json(
                &c.create_task(&self.principal, &arg(args, "subject")?, &opt(args, "detail").unwrap_or_default(), &scopes(args, "scope")?)
                    .map_err(failed)?,
            ),
            "task_claim" => to_json(&c.claim_task(&arg(args, "id")?, &self.principal).map_err(failed)?),
            "task_release" => to_json(&c.release_task(&arg(args, "id")?, &self.principal).map_err(failed)?),
            "task_complete" => to_json(
                &c.complete_task(&arg(args, "id")?, &self.principal, &opt(args, "summary").unwrap_or_default())
                    .map_err(failed)?,
            ),
            "log_append" => {
                let kind: EntryKind = serde_json::from_value(json!(arg(args, "kind")?)).map_err(|e| e.to_string())?;
                let entry = NewEntry {
                    kind: Some(kind),
                    topics: list(args, "topics"),
                    scope: scopes(args, "scope")?,
                    body: arg(args, "body")?,
                    evidence: Vec::new(),
                };
                to_json(&c.log_append(&self.principal, &entry).map_err(failed)?)
            }
            "log_read" => to_json(&c.log_new(&self.principal, &list(args, "topics")).map_err(failed)?),
            "log_resolve" => {
                let seq = args.get("seq").and_then(Value::as_u64).ok_or("missing integer argument `seq`")?;
                to_json(&c.log_resolve(seq, &self.principal, &opt(args, "note").unwrap_or_default()).map_err(failed)?)
            }
            "leases" => to_json(&c.leases().map_err(failed)?),
            _ => Err(format!("unknown tool {name}")),
        }
    }
}

//! The MCP protocol and tools against a real Trellis server.

use serde_json::{Value, json};
use trellis_client::Client;
use trellis_mcp::Server;
use trellis_server::{Background, Config, start_background};

fn server() -> (Background, tempfile::TempDir) {
    let dir = tempfile::tempdir().unwrap();
    let bg = start_background(Config::new("127.0.0.1:0".parse().unwrap(), dir.path().join("data"))).unwrap();
    Client::new(&bg.url(), "demo").unwrap().init().unwrap();
    (bg, dir)
}

fn agent(bg: &Background, name: &str) -> Server {
    Server::new(Client::new(&bg.url(), "demo").unwrap(), name)
}

fn call(server: &mut Server, name: &str, args: Value) -> (String, bool) {
    let reply = server
        .handle(&json!({ "jsonrpc": "2.0", "id": 1, "method": "tools/call", "params": { "name": name, "arguments": args } }))
        .unwrap();
    let result = &reply["result"];
    (result["content"][0]["text"].as_str().unwrap().to_owned(), result["isError"].as_bool().unwrap())
}

fn ok(server: &mut Server, name: &str, args: Value) -> String {
    let (text, is_error) = call(server, name, args);
    assert!(!is_error, "{name} failed: {text}");
    text
}

    let newer = s.handle(&json!({ "jsonrpc": "2.0", "id": 1, "method": "initialize", "params": { "protocolVersion": "2099-01-01" } })).unwrap();
    assert_eq!(newer["result"]["protocolVersion"], "2025-06-18");

//! `tl mcp` speaks newline-delimited JSON-RPC over stdio.

use std::io::{BufRead, BufReader, Lines, Write};
use std::process::{ChildStdin, ChildStdout, Command, Stdio};

use serde_json::{Value, json};

fn send(stdin: &mut ChildStdin, message: &Value) {
    writeln!(stdin, "{message}").unwrap();
}

fn request(stdin: &mut ChildStdin, lines: &mut Lines<BufReader<ChildStdout>>, message: &Value) -> Value {
    send(stdin, message);
    serde_json::from_str(&lines.next().unwrap().unwrap()).unwrap()
}

#[test]
fn tl_mcp_answers_over_stdio() {
    let tmp = tempfile::tempdir().unwrap();
    let bg = trellis_server::start_background(trellis_server::Config::new(
        "127.0.0.1:0".parse().unwrap(),
        tmp.path().join("data"),
    ))
    .unwrap();
    trellis_client::Client::new(&bg.url(), "demo").unwrap().init().unwrap();

    let mut child = Command::new(env!("CARGO_BIN_EXE_tl"))
        .args(["--server", &bg.url(), "--repo", "demo", "--as", "agent-1", "mcp"])
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .spawn()
        .unwrap();
    let mut stdin = child.stdin.take().unwrap();
    let mut lines = BufReader::new(child.stdout.take().unwrap()).lines();

    let init = request(&mut stdin, &mut lines, &json!({ "jsonrpc": "2.0", "id": 1, "method": "initialize", "params": { "protocolVersion": "2025-06-18" } }));
    assert_eq!(init["id"], 1);
    assert_eq!(init["result"]["serverInfo"]["name"], "trellis");
    send(&mut stdin, &json!({ "jsonrpc": "2.0", "method": "notifications/initialized" }));
    let opened = request(&mut stdin, &mut lines, &json!({ "jsonrpc": "2.0", "id": 2, "method": "tools/call", "params": { "name": "session_open", "arguments": {} } }));
    assert_eq!(opened["id"], 2);
    assert_eq!(opened["result"]["isError"], false);
    let written = request(&mut stdin, &mut lines, &json!({ "jsonrpc": "2.0", "id": 3, "method": "tools/call", "params": { "name": "write", "arguments": { "path": "a.md", "content": "hi" } } }));
    assert_eq!(written["id"], 3);
    assert_eq!(written["result"]["isError"], false);

    drop(stdin);
    assert!(child.wait().unwrap().success());
}
```
